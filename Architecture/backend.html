Layer 3 — Workflow Engine — State Machine (core/workflow_engine.py) — Deterministic Only, No LLM
CYCLE_CREATED→ ATTENDEE_REFRESH_SENT→ AVAILABILITY_COLLECTED→ MEETING_SCHEDULED→ SCORECARD_REQUEST_SENT→ SCORECARD_COLLECTION→ SCORECARD_COMPILED→ INTERNAL_ALIGNMENT→ VENDOR_PREP→ MEETING_IN_PROGRESS→ POST_MEETING_COMPLETE→ ARCHIVED
can_transition(from_state, to_state)
Validates if transition is allowed
transition(cycle_id, to_state)
Executes state move + updates DB
Enforcement Rules
Cannot send vendor brief before SCORECARD_COMPILED · Cannot generate minutes before notes exist · Cannot ARCHIVE without approved action items

Layer 4 — Orchestrator Layer (agents/orchestrator.py) — Routes every request to the correct Agent
AgentOrchestrator
  • resolve_agent(module, action) → selects correct agent class
  • run_agent(cycle_id, module, context) → executes agent
  • validate_workflow_state() → checks preconditions before run
  • log_to_agent_runs() → persists every execution to DB
  • handle_approval_gate() → holds output if requires_approval = true
Standard AgentResponse Contract (all agents return this exact shape)
{
  "status": "success | failed | partial | pending_approval",
  "agent": "scheduling_agent",
  "summary": "Attendee refresh form generated for 9 stakeholders.",
  "data": { ... },
  "warnings": ["3 stakeholders have not responded"],
  "next_actions": ["APPROVE_INVITE", "SEND_REMINDER"],
  "requires_approval": true,
  "run_id": "uuid"
}
