Layer 3 — Governance Workflow Engine — State Machine (Deterministic · No LLM · unchanged)
CYCLE_CREATED→ ATTENDEE_REFRESH_SENT→ AVAILABILITY_COLLECTED→ MEETING_SCHEDULED→ SCORECARD_REQUEST_SENT→ SCORECARD_COLLECTION→ SCORECARD_COMPILED→ INTERNAL_ALIGNMENT→ VENDOR_PREP→ MEETING_IN_PROGRESS→ POST_MEETING_COMPLETE→ ARCHIVED
Forward-only transitions
can_transition() enforced before every agent run · violations → HTTP 409
Prerequisite checks
Cannot brief vendor before scorecard compiled
Cannot generate minutes before notes exist
Human-in-the-loop gates (app layer)
Every AI "send" action pauses at ApprovalPanel → Lead approves → dispatched by a separate deterministic route. The agent only drafts — never acts.
