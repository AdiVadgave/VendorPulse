Layer 5 — Agent Orchestrator — Routes every module action to the correct agent · Enforces AgentResponse contract
AgentOrchestrator
resolve_agent(module, action) · validate_workflow_state() · run_agent(cycle_id, context)
handle_approval_gate() · log_to_agent_runs() · return AgentResponse
AgentResponse Contract
{ status · agent · summary · data · warnings · next_actions · requires_approval · run_id }
All agents return this exact shape — frontend never parses raw AI text
Audit Trail
agent_runs table
Every execution logged
input + output + status
